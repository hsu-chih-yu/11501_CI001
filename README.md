## File and Folder Organization
- `/On-Site_Examinations`: 每週上機考題目的程式碼與解題報告（Code Review Report）。
  - 資料夾命名規則：`Week<週次>_<題號>_UVa<題目編號>`，例如 `Week1_01_UVa10055`。
  - 每題資料夾包含：
    - `README.md`：解題報告（題目資訊、題意理解、解題策略、虛擬碼、程式碼、測試證據、反思、AI 使用紀錄）。
    - `src/uva<題目編號>.cpp`：最終版本程式碼。
    - `src/uva<題目編號>_fail.cpp`：初次提交未通過（WA / TLE）的版本（若有）。
    - `src/uva<題目編號>_original.cpp`：已 AC 但之後改良前的原始版本（若有）。
